# Noxie PC Enhancer

Windows PC cleaning, maintenance, performance monitoring and local diagnostics, with the Noxie cyan, blue and violet interface.

## Download

Get the installer or portable edition from [GitHub Releases](https://github.com/Gamerviciado/Noxie-PC-Enhancer/releases/latest). English is the default; Portuguese is available under **Settings → Language**.

Install **Noxie-PC-Enhancer-Setup-1.0.0.exe** once to move from the previous WPF preview to this Electron edition. The new edition uses a separate Windows application identity and data directory. Administrator approval is required. The Windows binaries currently have no code-signing certificate.

## Updates

The installed edition checks this repository at startup and once a day. Automatic downloads and the check interval can be changed in **Settings → App updates**. Applying an update requires **Restart and install**. Portable editions are updated manually.

No cloud account or cloud management platform is required. Updates are distributed through GitHub Releases. Release assets include `latest.yml`, a blockmap and SHA-256 checksums.

## Local tools

- System, browser, application and gaming cleanup
- Startup, service, registry and software management
- Storage analysis and maintenance
- Performance monitoring, diagnostic recording and history
- Optional scheduled tasks and recovery for supported changes

Cloud management, online breach checks and remote threat feeds are not configured. Local diagnostic history and export remain available.
